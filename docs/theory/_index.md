# Theory

States the concepts of an exposition and the grounds behind them, so that a decision of `ekthesis` can cite the claim that it rests on.

> [!WARNING] Notes under revision

- [Exposition](exposition.md): defines an exposition and what its audience changes
- [Glossary and notation](names-and-symbols.md): separates the names of a concept, which serve a reader, from its symbols
