# ekthesis documentation

Orients a reader toward the decisions, the theory and the proposals that specify how an author arranges an argument for an audience.

- [Architecture decisions](adr/_index.md): records the decisions that later work on `ekthesis` must respect
- [Theory](theory/_index.md): states the concepts of an exposition and the grounds behind them
- [Proposals](proposals/_index.md): collects candidate designs for the open goals of `ekthesis`
- [References](references/_index.md): states external work on reasoning and argumentation on its own terms
